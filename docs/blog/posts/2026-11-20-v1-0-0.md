# First stable release v1.0.0

The first stable release of Filetree is out with some small but significant features.

<!-- more -->

**v1.0.0** is Filetree’s first stable release — a polish pass on browsing, previews, and everyday file actions.

### What's new

- **web:** auto-open README when entering a folder ([#124](https://github.com/heapoftrash/filetree/issues/124))
- **web:** copy folder or selection path to clipboard ([#126](https://github.com/heapoftrash/filetree/issues/126))
- **web:** copy signed download link to clipboard ([#123](https://github.com/heapoftrash/filetree/issues/123))
- **web:** empty-folder upload drop zone ([#127](https://github.com/heapoftrash/filetree/issues/127))
- **web:** lazy image thumbnails in grid view ([#128](https://github.com/heapoftrash/filetree/issues/128))
- **web:** recent folders in sidebar ([#130](https://github.com/heapoftrash/filetree/issues/130))
- **web:** right-click context menu for file actions ([#129](https://github.com/heapoftrash/filetree/issues/129))
- **web:** Spacebar Quick Look fullscreen preview ([#125](https://github.com/heapoftrash/filetree/issues/125))
- **web:** toolbar file type filter chips ([#133](https://github.com/heapoftrash/filetree/issues/133))
- **web:** What's new link in sidebar version footer ([#134](https://github.com/heapoftrash/filetree/issues/134))
